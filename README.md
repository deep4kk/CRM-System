# CRM System

A comprehensive Google Apps Script CRM with lead pipeline, Kanban board, and communication integration.

## Features

- **Lead Pipeline**: Visual Kanban board for deal stages
- **Contact Management**: Track customers and companies
- **Activity Tracking**: Log calls, emails, meetings
- **Deal Management**: Track deal value, probability, expected close date
- **Drag & Drop Kanban**: Visual deal management with drag physics
- **Communication Integration**: WhatsApp/Email templates

## Setup

1. Create Google Sheet with: Users, Contacts, Companies, Deals, Activities, AuditLog
2. Deploy as Web App
